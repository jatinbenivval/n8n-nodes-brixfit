# v1.3.4 — 2026-06-01

## Bug Fix — Package size

### Problem

v1.3.3 ballooned from 24.5 kB to 2.3 MB because of two compounding issues:

1. **Over-sized icon** — `icon.png` was exported at 1250×1250px (1.1 MB). n8n renders node icons at 60px, so the extra resolution was entirely wasted.
2. **Duplicate inclusion** — the icon was listed in both the `files` array in `package.json` (source copy) and copied to `dist/` by the build script. Both copies ended up in the published tarball.

### Fix

- Resized `icon.png` from 1250×1250 → 60×60px using bicubic interpolation. File size: 1.1 MB → 5.9 KB (−99.5%).
- Removed `"nodes/Brixfit/icon.png"` from the `files` array. The `dist/` directory already contains the copy and covers it — no source duplication.
- Updated `homepage` in `package.json` to `https://brixfit.app`.

### Result

| Metric | v1.3.3 | v1.3.4 |
|--------|--------|--------|
| Package size | 2.3 MB | **31 kB** |
| Unpacked size | 2.4 MB | **135 kB** |
| Icon size | 1.1 MB × 2 | **5.9 KB × 1** |
| Files in tarball | 21 | 20 |
